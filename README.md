# flexda

### Non-developer, building AI-native ways of working.

생성형 AI 덕분에 비개발자로 데이터 분석, 자동화, AI 에이전트를 통해 다양한 호기심을 실제 결과물로 만들어보고 있습니다. 


## 요즘 하고 있는 것

- 반복하는 작업들을 skill 로 만들기 
- 내가 사용하는 작업환경을 편하게 자동화하기 
- 그동안 쓴 글들을 github 콘텐츠로 정리하기
